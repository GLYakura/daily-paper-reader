## 摘要
近场天线测量是表征电大孔径的基础，但近场到远场（NF-FF）变换的保真度取决于重建算法的假设及其对现实世界中不完美因素的鲁棒性，包括来自无人机扫描平台的不完美因素。经典基于FFT的模态展开在均匀采样的规范网格上高效，但在无法维持相位相干采集时失效。我们通过一种无相位的NF-FF算法解决了这一问题，该算法通过迭代相位恢复从仅幅度数据中重建远场。当采样变得稀疏或不规则时，即使基于幅度的方法也会失效，这促使了自适应稀疏逆辐射估计器（ASPIRE）的提出，这是一种全复数逆源框架，通过级联rSVD和正则化收缩在RWG基函数上求解矩量法问题。基函数之间的互耦被显式解析，从而在重建保真度上优于忽略耦合的逆源公式。该求解器通过多级快速多极子方法引擎和Numba即时编译加速，在N=100K时相对于稠密评估实现了矩阵-向量积时间1.2倍的减少和高达15倍的内存降低。在不同频段和定位/截断误差场景下，该流程保持了算法稳定性，并实现了亚度波束宽度重建误差。这些结果建立了一个面向固定和基于无人机的近场测量平台算法选择的误差感知框架。

## Abstract
Near-field antenna measurements underpin the characterization of electrically large apertures, yet the fidelity of the Near-Field to Far-Field (NF-FF) transformation depends on the reconstruction algorithm's assumptions and robustness to real-world imperfections, including those from drone-based scanning platforms.   Classical FFT-based modal expansion is efficient on uniformly sampled canonical grids but fails when phase-coherent acquisition cannot be maintained. We address this via a phaseless NF-FF algorithm reconstructing the far field from amplitude-only data through iterative phase retrieval. When sampling becomes sparse or irregular, even amplitude-based methods break down, motivating the $\textbf{Adaptive Sparse Inverse Radiation Estimator (ASPIRE)}$, a full-complex inverse source framework that solves a Method-of-Moments problem over RWG basis functions via cascaded rSVD and regularized shrinkage. Mutual coupling between basis functions is explicitly resolved, improving reconstruction fidelity beyond coupling-agnostic inverse-source formulations. The solver is accelerated via a Multilevel Fast Multipole Method engine with Numba just-in-time compilation, achieving a $1.2\times$ reduction in matrix-vector product time and up to $15\times$ lower memory usage relative to dense evaluation at N=100K.   Across frequency bands and positioning/truncation error scenarios, the pipeline sustains algorithmic stability and achieves sub-degree beamwidth reconstruction error. These results establish an error-aware framework for algorithm selection across fixed and drone-based near-field measurement platforms.

## 1. 核心问题与研究动机

- **背景**：电大尺寸天线的远场方向图测量若采用直接远场测量，需要极远的测量距离，成本高昂且不现实，因此近场（NF）测量成为标准方法。传统方法在微波暗室内使用高精度定位转台，但设施昂贵且受限于天线尺寸。
- **问题**：无人机天线测量系统（DAMS）作为低成本户外替代方案，将探头安装在带有RTK-GNSS定位的UAV上，可在灵活扫描面上采集近场数据。然而无人机平台引入了暗室测量中不存在的新误差源：
  - 风载和飞行控制器动态导致的定位抖动（毫米级）；
  - 电池续航限制导致的扫描区域截断；
  - 长飞行时间内发射-接收链路相位相干性可能丢失。
- **核心挑战**：经典 FFT 模态展开方法假设均匀采样、规范网格和完整相位信息，在无人机误差条件下会因频谱泄漏和混叠而退化。因此需要开发对相位缺失、采样稀疏/不规则、定位抖动更鲁棒的近远场变换算法。

## 2. 方法论

### 2.1 三类算法框架

| 方法 | 相位需求 | 采样要求 | 核心机制 |
|------|----------|----------|----------|
| FFT-Modal | 需要全相位 | 均匀规范网格 | 2D FFT 计算平面波谱，相位校正传播后合成远场 |
| Phaseless GS | 仅幅度 | 均匀网格，双平面 | Gerchberg-Saxton 迭代在两个平行平面间角谱传播，恢复相位 |
| **ASPIRE** | 全复数（相位可用时）或经扩展后用于无相位场景 | 可处理稀疏/不规则 | 逆源重建，RWG基函数上的矩量法求解，级联rSVD + ℓ1正则化收缩 |

### 2.2 ASPIRE 核心流程

**正向模型**：
```
u = G x + n
```
其中 G ∈ C^(M×N) 为前向算子，编码自由空间并矢格林函数在RWG基函数与探针位置之间的作用；x 为 N 个未知等效电流系数；u 为 M 个测量电压。基于完整 MoM 阻抗公式构造 G，显式捕获基函数间互耦。

**Stage 1 — 降维**：使用随机化SVD对 G 进行分解，通过奇异值衰减相对噪声下限确定数值秩 k，将 C^N 投影到 C^k 以抑制噪声放大。

**Stage 2 — 稀疏恢复**：
- C波段：使用 FISTA 加速迭代收缩求解器；
- X波段：由于波长短导致条件数增大，FISTA 动量项过冲不稳定，改用无记忆 ISS 迭代：

```
zt = xt − (1/L_lip) · G^H (G xt − u)
x(i)_{t+1} = max( |z(i)_t| − λ/L_lip, 0 ) · sign(z(i)_t)
```
- 恢复后的 x̂ 在其支撑集 S* 上通过最小二乘去偏，再合成远场：E_FF = F x̂

**MLFMM + Numba JIT 加速**：
- 用多层快速多极子方法在 O(N log N) 时间和内存内计算矩阵-向量积，替代 O(N²) 稠密运算；
- 纯 Python + Numba JIT 编译实现，避免 Fortran/C 依赖；
- 在 N=100K 时，MVP 时间降低 1.2×，内存使用降低约 15.7×（48GB→3.06GB）。

## 6. 主要结论

- **精度结论**：ASPIRE 在两个频段都达到 ≤0.3° 的波束宽度重建误差（C 波段 −0.30°，X 波段 −0.20°），优于 FFT-Modal 和 Phaseless GS。
- **误差趋势**：
  - FFT-Modal：从 C 波段到 X 波段相对误差从 5.9% 升至 6.8%，与抖动占波长比例增大一致（0.08λ→0.12λ）；
  - Phaseless GS：从 14.1% 降至 6.8%，说明 C 波段 GS 的主要误差源是扫描截断而非抖动（幅度恢复对突发截断的宽角能量极敏感）。
- **方向图保真度**：X 波段 ±70° 范围内，ASPIRE 与 CATR 的 Pearson 相关系数 r=0.97（dB），优于 FFT-Modal（r=0.87）和 GS（r=0.82），差距在 ±20° 以外最明显。
- **计算结论**：MLFMM 交叉点约在 N≈100K，此后相对稠密方法既有速度优势又有内存优势；Numba JIT 使加速在纯 Python 环境下可用，内存最多降低约 15.7×。
- **算法选择框架**：
  - 相位可用且均匀采样 → FFT-Modal；
  - 无相位硬件但均匀网格 → Phaseless GS；
  - 无人机平台（抖动/截断/不规则采样）→ ASPIRE；
  - 相位可靠时性能排序：ASPIRE ≫ FFT-Modal > GS；相位不可用时排序变为 ASPIRE > GS > FFT-Modal。
