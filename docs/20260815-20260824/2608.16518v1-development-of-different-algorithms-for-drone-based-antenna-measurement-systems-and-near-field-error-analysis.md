## 摘要
近场天线测量支撑着电大尺寸孔径的特性表征，然而近场到远场（NF-FF）变换的保真度取决于重建算法的假设及其对实际不完美因素的鲁棒性，包括来自无人机扫描平台的误差。经典的基于FFT的模态展开在均匀采样的规范网格上高效，但当无法维持相位相干采集时则失效。我们通过一种无相位的NF-FF算法解决这一问题，该算法通过迭代相位恢复从仅幅度数据重建远场。当采样变得稀疏或不规则时，即使基于幅度的方法也会失效，这促使我们提出自适应稀疏逆辐射估计器（ASPIRE），这是一种全复值逆源框架，通过级联rSVD和正则化收缩在RWG基函数上求解矩量法问题。基函数之间的互耦被显式解析，相比忽略耦合的逆源公式提高了重建保真度。求解器通过多层快速多极子引擎和Numba即时编译加速，在N=100K时，与稠密求值相比，矩阵-向量积时间减少1.2倍，内存使用量降低高达15倍。在不同频段和定位/截断误差场景下，该流程保持算法稳定性，并实现亚度波束宽度重建误差。这些结果建立了一个面向固定和无人机基近场测量平台的算法选择的误差感知框架。

## Abstract
Near-field antenna measurements underpin the characterization of electrically large apertures, yet the fidelity of the Near-Field to Far-Field (NF-FF) transformation depends on the reconstruction algorithm's assumptions and robustness to real-world imperfections, including those from drone-based scanning platforms.   Classical FFT-based modal expansion is efficient on uniformly sampled canonical grids but fails when phase-coherent acquisition cannot be maintained. We address this via a phaseless NF-FF algorithm reconstructing the far field from amplitude-only data through iterative phase retrieval. When sampling becomes sparse or irregular, even amplitude-based methods break down, motivating the $\textbf{Adaptive Sparse Inverse Radiation Estimator (ASPIRE)}$, a full-complex inverse source framework that solves a Method-of-Moments problem over RWG basis functions via cascaded rSVD and regularized shrinkage. Mutual coupling between basis functions is explicitly resolved, improving reconstruction fidelity beyond coupling-agnostic inverse-source formulations. The solver is accelerated via a Multilevel Fast Multipole Method engine with Numba just-in-time compilation, achieving a $1.2\times$ reduction in matrix-vector product time and up to $15\times$ lower memory usage relative to dense evaluation at N=100K.   Across frequency bands and positioning/truncation error scenarios, the pipeline sustains algorithmic stability and achieves sub-degree beamwidth reconstruction error. These results establish an error-aware framework for algorithm selection across fixed and drone-based near-field measurement platforms.

# 论文总结：基于无人机的天线测量系统不同算法开发及近场误差分析

## 1. 核心问题与整体含义（研究动机和背景）

- 天线辐射方向图的精确表征对通信和雷达系统至关重要。对于电大尺寸天线，直接远场测量需要极大的测试距离，因此近场（NF）测量成为标准手段。
- 传统近场测量依赖暗室和精密定位器，成本高且受天线尺寸限制。无人机基天线测量系统（DAMS）作为一种户外低成本替代方案被提出，但引入了暗室测量中不存在的新误差源：
  - **定位抖动**：风载和飞控动力学导致的 UAV 位置偏差；
  - **扫描截断**：电池续航限制导致扫描区域有限；
  - **相位相干性丢失**：长时间飞行中发射参考与接收链路之间可能出现相位漂移。
- 经典 FFT 模态展开方法假设均匀采样、规范网格和完整相位信息，在无人机平台上述误差下性能退化严重；无相位方法虽放松相位要求，但仍依赖均匀网格；传统逆源方法忽略互耦，在高频下精度受限。
- 整体含义：需要开发鲁棒、误差感知的近远场变换算法，能够在无人机平台的非理想条件下实现高精度方向图重建，并为不同测量平台提供算法选择依据。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

论文提出并比较了三类方法，重点推出 **ASPIRE**（Adaptive Sparse Inverse Radiation Estimator）框架：

- **基线方法对比框架**
  - **FFT-Modal 方法**：基于均匀采样近场数据的 2D FFT 计算平面波谱，通过相位校正传播算子得到远场。要求均匀采样、全相位信息、足够扫描范围。
  - **无相位 Gerchberg–Saxton（GS）算法**：利用两个平行平面（间距 Δz=3λ）上的幅度测量，通过角谱传播在平面间迭代，恢复相位并重建远场。仅需幅度硬件，但仍限于均匀网格。

- **ASPIRE 核心方法**
  - 基于逆源问题建模：将 AUT 包围在 Huygens 面上，离散为三角面片，使用 RWG 基函数表示等效电流。前向模型为：
    \[
    u = Gx + n
    \]
    其中 \(G\in\mathbb{C}^{M\times N}\) 是自由空间并矢格林函数构成的 MoM 阻抗矩阵，显式包含基函数间**互耦**。
  - 利用等效电流在物理上的稀疏性（只有导电部分有显著电流），分两阶段求解：
    - **阶段一：维度缩减** — 使用**随机化 SVD（rSVD）** 对 G 做降维，通过奇异值衰减确定数值秩 k，投影至低维空间并抑制噪声放大。
    - **阶段二：稀疏恢复** — 采用迭代收缩求解器（ISS），迭代公式为：
      \[
      z_t = x_t - \frac{1}{L_{\mathrm{lip}}} G^H(Gx_t - u)
      \]
      \[
      x_{t+1}^{(i)} = \frac{z_t^{(i)}}{\left|z_t^{(i)}\right|} \max\left(\left|z_t^{(i)}\right| - \frac{\lambda}{L_{\mathrm{lip}}}, 0\right)
      \]
      其中 \(L_{\mathrm{lip}}\) 是 \(G^HG\) 的 Lipschitz 常数，\(\lambda\) 为经验正则化参数，将小于阈值 \(\lambda/L_{\mathrm{lip}}\) 的系数置零，从而消除非辐射体上的电流。
    - 在 C 波段使用 FISTA 动量加速；在 X 波段因矩阵条件数增大导致 FISTA 不稳定，改用无记忆 ISS 版本保证收敛。
    - 恢复后通过支持集上的最小二乘进行去偏，再通过远场映射 \(E_{FF}=F\hat{x}\) 合成远场。

- **MLFMM 加速与 JIT 编译**
  - 为规避稠密矩阵 \(O(N^2)\) 的存储和计算瓶颈，采用**多层快速多极子方法（MLFMM）**实现矩阵-向量积（MVP），复杂度降至 \(O(N\log N)\)。
  - 实现采用 **Numba JIT 编译**的纯 Python 代码，无需 Fortran/C 依赖，获得近原生速度。
  - 在 N=100K 时，MLFMM 相比稠密求值将 MVP 时间降低约 1.2 倍，内存降低 15.7 倍。

## 6. 主要结论与发现

- **重建精度**：
  - ASPIRE 在 C 波段 ΔBW = −0.30°，X 波段 ΔBW = −0.20°，达到亚度级误差，优于 FFT-Modal（分别为 −1.10° 和 +0.30°）和 Phaseless GS（−2.60° 和 −0.30°）。
  - 相对误差方面，FFT-Modal 从 C 波段 5.9% 升至 X 波段 6.8%，与 jitter 占比增大一致；GS 从 14.1% 降至 6.8%，说明 C 波段 GS 的主要误差来自扫描截断而非抖动。
  - ASPIRE 在 ±70° 范围内与 CATR 真值 Pearson 相关系数 r=0.97（dB 域），远高于 FFT-Modal 的 0.87 和 GS 的 0.82，尤其在 ±20° 以外优势明显。

- **性能与可扩展性**：
  - MLFMM+Numba JIT 在 N≈100K 附近交叉优于稠密实现，内存降低 15.7 倍，使 10^5+ 未知量在常规硬件上可求解。

- **算法选择指导**：
  - FFT-Modal 适用于保持均匀采样和相位相干的暗室常规测量。
  - Phaseless GS 适用于无条件获得相位硬件但网格均匀的场景。
  - ASPIRE 推荐用于无人机平台，因其能应对定位抖动、扫描截断和不规则采样，且显式建模互耦。
  - 有相位时的性能层次：ASPIRE ≫ FFT-Modal > Phaseless GS；无相位时 FFT-Modal 失效，相位恢复类方法（如 GS）更合适。

## 7. 优点

- **方法创新点明确**：不同于传统逆源方法，ASPIRE 显式解析 RWG 基函数间的互耦，在物理建模上更完善，从而在高频下获得更高保真度。
- **求解器设计合理**：rSVD 降维 + ℓ1 正则化迭代收缩 + 支持集去偏，兼顾噪声鲁棒性和稀疏物理先验。
- **工程实现高性能**：MLFMM + Numba JIT 在纯 Python 环境中实现了接近原生的计算速度，并大幅降低内存占用，使得大规模未知量（>10^5）在消费级硬件上可行。
- **误差分析和算法选择框架具有实用性**：同时考虑了定位抖动、截断和相位丢失三类无人机平台特有的误差，比较了三种典型算法，给出了清晰的选用指引。
- **使用真实 CATR 数据作为基准**，非仿真合成数据，结论更有说服力。
