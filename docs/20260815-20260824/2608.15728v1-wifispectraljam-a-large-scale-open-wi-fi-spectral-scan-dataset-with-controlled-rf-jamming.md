## Abstract
WiFiSpectralJam is a Wi-Fi spectral-scan dataset comprising 14.52 GB, 96,090 CSV files, and 522,771,130 ordered spectral observations using commodity Wi-Fi sensing hardware. Measurements were acquired with a Raspberry Pi Compute Module 4 equipped with a Qualcomm Atheros QCA9880 802.11ac network interface and the Linux ath10k spectral-scan interface. The dataset spans active and passive scan modalities across the 2.4 and 5 GHz bands and includes real-world benign background captures, benign RF-chamber floor captures, and controlled RF-jamming captures generated with a HackRF One. Jamming conditions vary by transmit power, target channel, and, in the active subset, waveform type. The release provides the raw spectral-scan records together with a file-level metadata manifest, derived spectral-summary features, validation outputs, and reproducible benchmark protocols. These resources support reuse in RF interference characterisation, jamming detection, spectrum monitoring, distribution-shift evaluation, and machine-learning studies using commodity-NIC spectral measurements. The dataset is publicly available at: https://www.kaggle.com/datasets/daniaherzalla/radio-frequency-jamming/data.

## 二、论文提出的方法论

### 核心思想
使用低成本商用硬件（Raspberry Pi CM4 + Qualcomm Atheros QCA9880 802.11ac 网卡）和 Linux ath10k 驱动的频谱扫描接口，采集带有明确标注的频谱数据。干扰由 HackRF One 软件无线电通过 JamRF 框架生成，干扰条件（功率、目标信道、波形）被系统化控制，从而支持从“匹配分布分类”到“分布偏移泛化”的一系列基准评估。

### 关键技术细节
- **采集平台**：CM4 主机 + QCA9880 网卡，通过 debugfs 接口导出 FFT 频谱字段；接收与干扰距离固定 20 cm，位于 Candela CT840A 射频屏蔽室内，保证恶意捕获的受控性。
- **扫描模式**：
  - **主动扫描**：接收器锚定在操作信道（5805 MHz），短暂访问其他中心频率并返回；文件内观察数在操作信道显著更多（约 3700 条/文件），其他信道约 700 条/文件。
  - **被动扫描**：接收器按顺序扫描配置频率，无操作信道回访；各频率观察数分布更均匀。
- **数据设计**：
  - 良性数据：射频暗室底噪（无干扰）和真实室内背景（高/低活动性位置）。
  - 恶意数据：由 HackRF One 产生，主动子集使用高斯噪声和单音波形在 5805 MHz（功率 -40/-10/0/+10 dBm）；被动子集仅使用高斯噪声，功率 +3/+6/+9/+12 dBm，目标信道 2412、2457、5180、5745 MHz。
- **标签生成**：从文件夹层级和文件名确定性解析，无后验推断；结构性不适用字段记为 N/A。
- **特征工程**：原始 CSV 为基本数据单元；基准测试使用文件级聚合特征，每个观测行包含 8 个频谱字段（freq1、noise、max_magnitude、total_gain_db、base_pwr_db、rssi、relpwr_db、avgpwr_db）。对 7 个关键量（排除 freq1 和原始 rssi）计算 9 个统计量（均值、标准差、最小值、四分位数、中位数、四分位数、最大值、偏度、峰度），得到 **63 维特征向量**；另有一个 **54 维消融表示**（移除全部 noise_* 特征）。
- **基准协议**：所有划分均为 **文件级**，避免行级数据泄漏。包括：
  - 匹配分布随机文件级划分（pooled、active-only、passive-only 等）。
  - 留出实验：留出特定干扰功率、主动波形、或良性背景位置。
  - 射频暗室底噪控制：仅用暗室数据训练和测试，排除“真实环境 vs 暗室”的域捷径。
  - 跨扫描模式迁移：主动→被动、被动→主动。
- **分类器**：逻辑回归、随机森林、直方图梯度提升、XGBoost、LightGBM、多层感知机（MLP）。指标包括准确率、平衡准确率、精确率、召回率、F1、ROC-AUC、平均精度（AP），并报告固定阈值 0.5 下的 F1 以及阈值无关的 AUC/AP，以区分排名质量与阈值转移问题。

## 六、论文的主要结论与发现

1. **匹配分布分类接近饱和**：树模型和 boosting 在几乎所有子集上达到 F1≈1.0，逻辑回归和 MLP 在 pooled/passive 5 GHz 上稍弱。
2. **留出条件揭示真实泛化差距**：active -40 dBm 和 passive 5 GHz +3 dBm 是困难场景；被动 2.4 GHz 和 5 GHz 的留出表现差异巨大（2.4 GHz 饱和，5 GHz F1 很低但 AUC 较高）。
3. **噪声字段不是唯一捷径**：移除 noise_* 特征后，匹配分布性能和暗室控制仍饱和；噪声特征仅对部分迁移场景有帮助。
4. **跨扫描模式迁移显著困难**：主动→被动 F1 最高约 0.44，被动→主动最高约 0.56，证实扫描模式是一个真实域偏移。
5. **固定阈值 F1 与排名指标可能严重背离**：例如留出单音波形时，随机森林 AUC/AP=1.000 但 F1=0.000，说明问题主要在于分数标度迁移而非不可分。
6. **被动带间存在反向特征偏移**：2.4 GHz 和 5 GHz 的干扰特征变化方向相反，因此被动结果必须分带报告。

## 七、优点

- **规模大、覆盖广**：5 亿+观测，双频段，主动/被动模式，多种功率、目标信道和波形。
- **可复现性极强**：提供完整元数据清单、特征表、验证输出、公开代码和固定种子划分逻辑。
- **严谨的基准设计**：文件级分割、多指标（F1/AUC/AP）对比、阈值效应与排名效应分离、消融和置换重要性审计。
- **强调实际部署域**：使用商用网卡而非专用仪器，贴近真实环境；主动/被动扫描均被明确视为不同域，并设计了跨模式迁移实验。
- **公开可用**：Kaggle 上免费获取，附带详细文档和可执行验证笔记本。

## 八、不足与局限

- **硬件和场景特定**：数据仅来自 CM4 + QCA9880 + HackRF One 和固定 20 cm 暗室几何，换硬件或部署环境可能需要适配。
- **缺少时间戳和相位信息**：原始记录只有扫描顺序，无显式时间戳，不能当成均匀采样时间序列；也不包含相位、完整 FFT 向量或原始 I/Q，不适合相位敏感建模。
- **恶意捕获无合法流量**：标签代表“干扰器存在与否”，而非真实链路降级；不包含移动、多干扰器、反应式攻击或非受控真实恶意场景。
- **主动子集条件样本较少**：每个波形-功率组合只有 101–230 个文件，某些细粒度留出统计稳定性有限。
- **被动文件长度差异大**：文件内观测数从 1k 到 17k 不等，虽然行数不直接用为特征，但高阶层总结仍可能受观测数影响。
- **留出基线的阈值转移问题**：多个模型在固定阈值下 F1 极低但 AUC 高，说明实际部署需要额外的分数校准，数据集本身不提供现成的阈值解决方案。
- **未报告训练算力**：论文没有说明模型训练的资源开销，对于大规模深度学习方法可能缺乏参考。
